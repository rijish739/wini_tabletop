Cheat Sheet & Quick Reference

Ticket 10: Workload Identity Federation Architecture

Zero static keys, OIDC trust, and human-gated cloud spend for CI testing

1. Core Concept Map

GitHub Actions Runner (CI)
      │
      │ 1. Request signed OIDC JWT (permissions: id-token: write)
      ▼
GitHub OIDC Provider (token.actions.githubusercontent.com)
      │
      │ 2. Issues JWT with claims: sub, repository, environment="billed-eval"
      ▼
GCP Workload Identity Provider (github-oidc in pool github-actions-pool)
      │
      │ 3. Validates Issuer & Attribute Condition:
      │    assertion.repository == 'org/repo' && assertion.environment == 'billed-eval'
      ▼
GCP Service Account (wini-billed-ci@PROJECT_ID.iam.gserviceaccount.com)
      │
      │ 4. Impersonated via roles/iam.workloadIdentityUser
      ▼
Vertex AI API (asia-south1)
      │
      │ 5. Short-lived access token with roles/aiplatform.user
      ▼
Evaluations (safety_eval.py / personal_data_eval.py)

2. Secrets & Configuration Summary

Key Name Where Configured Example Value
WIF_PROVIDER GitHub Environment Secret (billed-eval) projects/123456789/locations/global/workloadIdentityPools/github-actions-pool/providers/github-oidc
WIF_SERVICE_ACCOUNT GitHub Environment Secret (billed-eval) wini-billed-ci@<PROJECT_ID>.iam.gserviceaccount.com
VERTEX_REGION Environment / Runtime Default asia-south1 (Mandatory for DPDP)

3. The 5-Step CI Job Lifecycle in .github/workflows/ci.yml

  1. Guard Step: Fails with ::error:: annotation if WIF_PROVIDER or WIF_SERVICE_ACCOUNT is unset.
  2. Checkout: actions/checkout@v4.
  3. Auth Step: google-github-actions/auth@v2 exchanges OIDC JWT for a Google Cloud federated access token.
  4. Cost Notice: Displays cost model to reviewer (calls are per uncached row; cached rows are free).
  5. Execution / Stub: Runs eval/*.py --collect (or exits 1 in stub state prior to Ticket 12/13).
